CALBENCH

Torque Calibration Certificates, Labels & Traceability

Open Desktop Demo Open Mobile Demo

A working prototype covering data entry, calibration maths, BS EN ISO 6789 certificates, Code 128 barcode labels, and a searchable SQLite store — built to demonstrate software engineering ability alongside torque and force metrology experience.

This is a static hosted version. Certificate calculations, barcode generation, and the UI all run client-side and work fully here. Search, save, and scan-lookup features rely on the Python backend and require running the project locally — see the README for setup.
